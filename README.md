# Calibrating Diffusion First-Passage-Time RUL Prognostics on Rolling Bearings

Reproducibility repository for the paper:

> **Predict the Distribution, Not the Trajectory: Calibrating Diffusion
> First-Passage-Time RUL Prognostics on Rolling Bearings.**
> Javed Sameer, Hongwei Mo (corresponding), Sumbal Ruhma.
> College of Intelligent Systems Science and Engineering, Harbin Engineering
> University. *China Automation Congress (CAC), 2026 (accepted).*

The paper is an empirical **calibration audit**: it asks whether the remaining-useful-life
(RUL) distributions produced by diffusion-generated degradation trajectories (via their
first-passage time across a failure threshold) are *calibrated* and — through controlled
ablations — where any miscalibration comes from. It is not a new-algorithm paper; the
recalibration arms and the direct-RUL control are existing methods used to localize the cause.

## Pre-specified protocol

This was a **pre-specified** study. The analysis protocol — health-indicator
construction, failure-threshold rule, data splits, metrics, and acceptance criteria — was
fixed in [`PROTOCOL.md`](PROTOCOL.md) on **2026-07-20**, before
any model was built. `PROTOCOL.md` is included here verbatim so the pre-specification can be
inspected. (We call it *pre-specified* rather than *pre-registered* because it was not
lodged in an independent public registry ahead of the analysis.)

## Repository layout

```
PROTOCOL.md          Pre-specified protocol (committed 2026-07-20, before modeling)
REVIEWER_NOTES.md    Peer-review outcome + how each required revision was addressed
requirements.txt     Python dependencies
code/                All analysis code (see below)
data/                Pre-processed health-indicator (HI) trajectories (small .npz)
results/             Result JSONs used to build the paper's tables/figures
figures/             The three paper figures (regenerated by make_figures.py)
```

`code/`:

| file | purpose |
|------|---------|
| `diffusion_calib_diagnostic.py` | the diagnostic harness: diffusion + FPT rollout, direct-RUL control, recalibration arms, metrics, threshold-sweep ablation |
| `reproduce_tables.py`           | regenerate Tables I–II and the naive-vs-direct paired statistics from the result JSONs |
| `make_figures.py`               | regenerate the three paper figures into `figures/` |
| `preprocess_xjtu.py` / `preprocess_femto.py` | rebuild the HI `.npz` from the raw vibration datasets (optional) |

The **pre-processed HI trajectories are included** (`data/*.npz`), so every result can be
reproduced without downloading the raw vibration datasets.

## Data

The study uses two **public** run-to-failure rolling-bearing datasets. No proprietary or
confidential data is used or redistributed here; only the derived HI trajectories are
included.

- **XJTU-SY Bearing Datasets** — 15 bearings, 3 operating conditions, 25.6 kHz, one snapshot
  per minute. Wang et al., *IEEE Trans. Reliability*, 2018.
  Source: <https://biaowang.tech/xjtu-sy-bearing-datasets/>
- **PRONOSTIA / FEMTO Bearing Dataset** (IEEE PHM 2012 Data Challenge) — 17 bearings, 3
  conditions, 25.6 kHz, one snapshot per 10 s. Nectoux et al., *IEEE PHM*, 2012.
  A commonly used mirror: <https://github.com/wkzs111/phm-ieee-2012-data-challenge-dataset>

Please obtain each dataset from its original provider and respect its licence.

## Reproduce

```bash
pip install -r requirements.txt          # PyTorch (CUDA build recommended), NumPy, SciPy, pandas, matplotlib

# --- Main calibration audit + recalibration benchmark (20 seeds) ---
python code/diffusion_calib_diagnostic.py --dataset combined --seeds 20
python code/diffusion_calib_diagnostic.py --dataset combined --seeds 20 --fixed_d

# --- Threshold-sweep ablation (rollout vs. extrapolation), 20 seeds ---
python code/diffusion_calib_diagnostic.py --dataset combined --ablation --seeds 20

# --- Tables and figures (from the shipped result JSONs, no GPU needed) ---
python code/reproduce_tables.py          # prints Tables I-II + paired statistics
python code/make_figures.py              # writes the three figures into figures/
```

Results are written to `results/*.json`; figures to `figures/`. Runs are seeded and report
mean over seeds. GPU is recommended for the diagnostic (the diffusion training/rollout is
the bottleneck); CPU works but is slow. `reproduce_tables.py` and `make_figures.py` run in
seconds on CPU from the included JSONs.

### Rebuilding the HI trajectories from raw data (optional)

The `data/*.npz` files are already provided. To rebuild them, download the two datasets
above and set the raw-data paths at the top of `code/preprocess_xjtu.py` and
`code/preprocess_femto.py`, then run:

```bash
python code/preprocess_xjtu.py
python code/preprocess_femto.py
```
